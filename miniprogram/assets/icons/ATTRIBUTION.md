# 图标素材来源

界面图标直接取自 Lucide Icons 官方 SVG 图标库，图形路径未经重绘。

- 官方图标目录：https://github.com/lucide-icons/lucide/tree/main/icons
- 许可：ISC，完整许可文本见 [LICENSE-Lucide.txt](./LICENSE-Lucide.txt)，运行包内也附有 LICENSE-Lucide.json；许可说明：https://lucide.dev/license
- 使用的原始图标：arrow-up-right、book-open、book-open-text、chevron-right、compass、crosshair、house、layers、map-pin、rotate-cw、search、settings、shuffle、user-round、zap。
- SVG 仅替换线条颜色以适配现有深浅主题；图层、定位和图鉴三个 PNG 是同一 SVG 的 Canvas 兼容栅格版本，未改变图标路径。
