Globe material provenance

Color Map Source: globe-texture-realistic-seamless-source.png, a project-local
generated satellite-style equirectangular raster. It is not copied from
JackGit/xplan, NASA, a map tile provider, or a CDN. The asset was generated for
this project and then cleaned to remove the duplicated vertical seam while
keeping the full-world 2:1 projection.

This file lives in design/world/ on purpose: it documents build-time assets and
is not part of the WeChat code package. (It was moved out of
miniprogram/assets/world/ in Gate 2; the package no longer carries it.)

Runtime (shipped) — miniprogram/assets/world/, JPEG
  Color map      globe-texture-realistic-2048.jpg (2048 x 1024)
  Elevation map  globe-height-2048.jpg            (2048 x 1024)
  Specular map   globe-specular-2048.jpg          (2048 x 1024)

  2048 is the shipped tier. At 3x device density the globe sphere is about
  1012 px across and the visible hemisphere of a 2048 equirectangular map spans
  1024 texels, i.e. roughly 1:1 — lowering the tier would visibly soften the
  sphere. JPEG replaced PNG in Gate 2 because all three maps are photographic
  or continuous-tone content: PNG cost ~1748 KB/MP for the color map.

  Regenerate with:
    python scripts/prepare-globe-texture-variants.py
    python scripts/build-globe-material-maps.py
  Both outputs were verified byte-identical to the checked-in files.

Design (not shipped) — design/world/, PNG
  globe-texture-realistic-4096.png (4096 x 2048)
  globe-height-4096.png            (4096 x 2048)
  globe-specular-4096.png          (4096 x 2048)

  The 4096 tier is excluded from the WeChat code package: the three files total
  ~12.6 MB, which was 45% of the whole package before Gate 2, and only the
  development query `?texture=4096` could reach them — normal runs always load
  the 2048 tier.

  The runtime resolves tiers through miniprogram/engine/globe-texture-source.ts.
  When GLOBE_TEXTURE_REMOTE_BASE is set (CDN / WeChat cloud storage), requesting
  4096 switches to that base URL automatically; with no base configured the
  request degrades to the packaged 2048 tier instead of failing.

  Note the 4096 material maps are upscales of the 2048 color raster, so they
  carry no information the 2048 maps lack.

Elevation / Height Map
  A local, low-amplitude relief cue built by scripts/build-globe-material-maps.py.
  It adds broad synthetic emphasis to the Himalaya/Tibetan Plateau, Andes,
  Rockies, Alps and East African highlands; it is a bump cue, not a measured
  global DEM and must not be used for geographic elevation calculations.

Specular Map
  Derived locally from the color map: ocean receives a higher response, land a
  rougher response, and ice an intermediate response.

License / Usage: project-local generated assets, permitted for use within Geo
Explorer. No third-party imagery or xplan source code, shader, texture, or
asset is redistributed by this renderer. (The legacy globe-texture.png Natural
Earth fallback and the unused 1024-final variant were removed in the Final
Acceptance cleanup, 2026-09-12; both are regenerable via
scripts/build-globe-texture.py and scripts/prepare-globe-texture-variants.py.)

Processing: OpenAI Image Generation produced the local colour source; local
projection cleanup, Lanczos resampling and a restrained unsharp pass produced
the runtime colour maps. Pillow plus deterministic Gaussian-blurred relief and
material masks produced the height/specular maps.

Runtime: all shipped maps are local/offline assets; the WebGL renderer makes no
map tile or network request.
