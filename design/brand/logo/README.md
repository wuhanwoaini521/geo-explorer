## 使用约定

- 微信头像上传：`avatar-emblem-1024.png`（≥144px、PNG、≤2MB 均满足注册要求；每自然月可改 5 次）。
- 正式对外物料（分享图/截图角标/宣传页）：`logo-lockup-*` 或 `logo-mark-*`。
- **当前小程序页面未消费该 Logo**（避免无引用的图片进入 dist 包体）；未来如需要（关于页/启动页），再按媒体管线登记进 `MediaManifest`，不要直接硬编码路径。
- 深色/浅色背景适配：Logo 为浅纸底暖色系，放在深色 UI 上时建议加浅色圆底或用 `avatar-emblem` 的方形版本。
