## 2. 逐世界叙事走查

### everest：地貌观察之旅（海拔轴 0 → 8,848.86 m）
- 知识触发序：季风林带(2,600) → 直减率(3,600) → 树线(4,400) → 雪线(5,700) → 冰川流动(6,300) → 死亡区(7,950) → 高程测量(8,848.86)。与环境变化同步：先自然带、后冰雪、再低压、终以测量收束——叙事连贯。
- Waypoint 卡与知识节点互补（如冰瀑点 → k08 冰川流动 → 随堂题），无重复表述。
- 风险：无。

### mariana：垂直下潜（深度轴 0 → 10,935 m）
- 新增 7 个下潜里程碑后，每个海洋带都有可点击的观察点；知识触发序：生物发光(600) → 黑暗带(1,000) → 水压(2,000) → 深渊带(4,000) → 超深渊(6,000) → 下潜史(10,500) → 挑战者深渊(10,935)。
- 「为什么这里重要」逐点成立：温跃层讲声学、微光带讲迁徙、深层讲海雪、沟坡讲俯冲、临底讲压载、坐底讲 60 年技术史。
- 修复：原文件 6 处乱码/错字已清（「呼吸无法」「界宇宙共识」「硫深海生命」「奋斗号」→「奋斗者」号等）。

### fuji：火山攀登（海拔轴 2,305 → 3,776 m，新世界）
- 差异化节奏：起点即「车路五合目」（火山世界的独有叙事），知识序：合目制度(2,305) → 林线(2,400) → 休止角砾石坡(2,700) → 大泽崩れ(3,100) → 御来光夜爬(3,450) → 宝永喷发(3,500) → 山顶火口(3,680) → 3,776.24 m 高程(终点)。
- 观察链完整：每次抬头/低头都有具体对象（山小屋防风结构、火山砂分选、火口内壁层理、脚下石灰岩）。
- 与 everest 的区别可感知：无植被终点的火山 + 文化层（合目/御来光/世遗）替代冰川叙事。

### colorado：下切阅读地层（谷深轴 0 → 1,389 m，新世界）
- 差异化节奏：每个 waypoint 都绑定一段岩层与一个地质年代，HUD 的「岩层年代」指标在托托平台→内峡之间从 5 亿年跳到 17.5 亿年——大不整合面成为旅程高潮。
- 温度反向（越下越热）与 everest 相反，四个世界的「测量/环境变化」完全不同质。
- 终点水文叙事（明亮天使溪/科罗拉多河）收束于「水的来处」，与开头「峡谷的诞生」首尾呼应。

## 3. 文风检查

- 无「令人惊叹/鬼斧神工/叹为观止」式空话；每个节点落到具体事实、可观察对象、原因与关系。
- 移动端优先：summary 一句话 + facts + detail 分层，detail 均在 100–200 字量级，无百科 dump。
- 专有名词处理：中文名为主，英文名在 `nameEn` 字段与首次出现处保留。
