## Important

Do NOT treat geographic numbers or waypoint positions shown in the mockup as authoritative.

Runtime geographic data must come from:

- RouteIndex
- authoritative elevation
- Environment Model
- verified source data

## Design principle

Terrain is the primary visual content.

UI should behave as a lightweight information overlay rather than a dashboard.

The final product should feel closer to:

- Google Earth
- National Geographic
- modern scientific visualization

Avoid:

- game-style HUD
- cyberpunk UI
- excessive cards
- decorative fake terrain
- AI-generated imagery presented as real geographic evidence
