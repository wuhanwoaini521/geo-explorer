# 🌍 Geo Explorer

> 用手指把珠穆朗玛峰爬一遍，顺便学点地理。
> （也可以倒着下潜到马里亚纳海沟底部 —— 前提是你不恐深。）

一个微信小程序：**地理探索 + 知识解锁 + 随堂问答**。滑动屏幕推进海拔/深度，途中点亮知识节点、回答随堂测验，真实地理数据打底，拒绝瞎编。

## ✨ 这里面有什么

| 玩法 | 说明 |
|---|---|
| 🧗 **珠峰南坳攀登** | 从卢卡拉 2,600m 一路滑到 8,848.86m，途经昆布冰瀑、西库姆冰谷、南坳、死亡区——全程不用吸氧 |
| 🤿 **马里亚纳海沟下潜** | 表层阳光带一路下到 10,912m 挑战者深渊，看看水压怎么把人摁成薄片 |
| 📚 **知识库** | 32 条地理知识，探索中解锁的会点亮「已解锁」徽章，慢性收集癖福音 |
| 🏅 **挑战问答** | 三档难度，按难度记录最佳成绩（正确率优先，其次正确数），不服就再来一轮 |
| 📊 **实时环境指标** | 温度、气压、含氧量随位置实时变化——数字会说话：越往上越要命 |

**场景里的画面是真的**：珠峰地形不是画师手绘的示意画，而是用真实卫星高程数据（Copernicus GLO-30 DEM，30m 分辨率）渲染出来的三维地形。南坳攀登路线、八个营地路点，全都贴在真实山体上。爬的是数学意义上的珠峰。

## 🖼️ 视觉风格

「暖纸 / 古地图」风：淡黄纸底、墨色文字、琥珀金主色，外加一套克制的编辑排版。
没有赛博发光，没有彩虹渐变——我们想让你觉得自己在看一张考究的探险地图，而不是某个儿童早教 App。

## 🚀 跑起来

```bash
# 环境要求：Node.js + 微信开发者工具（Blender 仅在重渲染地形时需要）

npm install

npm run build     # 编译 TS + 拷贝资源 → dist/miniprogram/
npm run test      # 131 个单测（引擎/数据/工具函数，Node 环境跑）
npm run typecheck # TS 严格模式检查

# 然后用微信开发者工具打开仓库根目录
# （project.config.json 已配置 miniprogramRoot: dist/miniprogram/，工具加载构建产物）
```

> ⚠️ 改了源码记得 `npm run build`——开发者工具看的是 `dist/`，不是 `miniprogram/`。
> 我们不会说这是谁踩过的坑。

## 🗻 那 3D 地形是怎么来的

简短版：**我们让山自己长出来。**

1. 下载 Copernicus GLO-30 的两个 1° DEM 瓦片（珠峰刚好骑在 N27/N28 边界上，命运多舛）
2. `scripts/terrain/prepare_everest_dem.py` 裁剪出 86.70°E–86.99°E × 27.80°N–28.10°N，生成高程网格 + 雪线掩膜
3. Blender 把高程网格变成实体地形（Workbench 渲染，顶点着色：雪线以上白、以下岩石棕）
4. 相机机位（远景 A / 中景 B / 冲顶特写 C）各自渲染，再裁成小程序用的竖幅
5. 南坳路线由 8 个 GPS 路点 + Catmull-Rom 平滑生成 289 个控制点，贴着地形走，不穿山不悬空

所以探索页里你看到的三张全屏背景，是**同一座真山的三种视角**，按你的海拔硬切换：山脚看全景 → 半山看山脊 → 冲顶贴冰岩壁。

## 🧪 数据可信度

- 海拔/深度节点、温度气压均标注了参考来源（维基/公开资料），近似值会显式标记「近似」
- 路线营地高度用公开参考值，山体几何用 DEM 真值，两者各司其职
- 知识条目来源可溯源（`data/knowledge.ts`），随堂测验的解析讲人话
